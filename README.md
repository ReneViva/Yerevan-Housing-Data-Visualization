# Yerevan housing and commuting costs

Open **YerevanHousing.Rproj** in RStudio, open **Yerevan_Housing_Research.Rmd**,
and click **Knit**. The HTML and PDF appear in **outputs**. Open the HTML to read
the six-chart story; use **Show** to reveal a chart's code. Select any chart to
open its full-size image.

The two main files are the editable **Yerevan_Housing_Research.Rmd** and
**Yerevan_Housing_Code_Companion.docx**, which explains the same code and charts.

| Folder | What it contains |
|---|---|
| data | Four CSV inputs: cleaned rentals and road journeys, tariffs, wages, sources |
| figures | The six final charts, regenerated by Knit |
| outputs | The rendered HTML and PDF |
| references | A short explanation of sources, assumptions and course requirements |
| _archive | The previous version, original records, scripts and technical checks |

Normal use needs no development scripts or network access. The verified local
environment is R 4.5.0 with ggplot2, dplyr, tidyr, scales, rmarkdown and knitr;
RStudio provides Pandoc and the PDF uses the existing XeLaTeX installation.

The 276 advertisements describe one agency's sample. Rents are observed asking
prices; travel times and household costs are modeled examples.

The previous version is saved in local Git as `before-visual-simplification`
(`abcf7d5`) and in `_archive/previous-version`. Nothing is published remotely.
